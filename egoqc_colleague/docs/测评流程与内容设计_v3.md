# 第一部分：判据定义

这是所有提示词的基准，必须先钉死。

| 概念 | 定义 | 判定 |
|---|---|---|
| **采集设备** | 操作员**身上/腰间佩戴**的录制装置本体（深色、可能带屏幕），属于随身设备 | —— |
| **采集设备露出** | 该设备**或其屏幕**进入画面任何位置（下边缘、左右两侧、中央） | **删除** |
| 任务道具 | 桌上的积木、碗、以及**任务描述里明确要求操作的**平板/手机等 | 不算问题 |
| 固定家具 | 桌面、桌腿、隔断、墙面等环境结构 | 不算问题 |
| 出现时长 | 只要**任意一帧**出现即算（不需要全程） | —— |

**"露出"的宽松度**：只露出一角、屏幕未点亮、被手遮挡一部分，**都算出现**。

```

      ↓

      ↓
[5] 推理        本地千问，单次多问 → 结构化 JSON
      ↓
[6] 反证审计    仅对"判删除"或低置信的条目，再问一次"请找证据推翻"

# 第三部分：抽帧策略（针对"设备入画"优化）

设备在**身上**，所以在 ego 视角里它只会出现在**画面下缘/底部两侧**。这决定了抽帧方式：

| 通道 | 内容 | 用途 |
|---|---|---|
| **A 全片均匀** | 16–20 帧，铺满整条 | 任务完成度、整体模糊、无意义动作 |
| **B 底部加强** | **额外 6 帧，裁画面下 35% 区域**，放大到 1024px | **采集设备露出**（关键） |
| **C 连续帧** | 3 段 × 8 帧（间隔 0.1s），取开头/中段/结尾 | 抖动、长时间静止 |

**分辨率**：全片帧 1024px 宽；底部加强帧从原图裁下 35% 高度再放大到 1024px（≈3 倍有效放大）。

> 依据：我在 Step 0 里用 3 倍放大才勉强看清底部细节，且设备可能只露出一角 —— **B 通道是问题 1 能不能抓到的关键**。

```

## 4.1 问题 1：采集设备露出（覆盖 ≈50%，**最高优先级**）

```
【问题1】画面中是否出现了"操作员身上佩戴的采集设备"？

【什么是采集设备】
操作员随身佩戴的录制装置本体：深色（深蓝/深灰/黑色）的方形或带屏幕的小型装置，
通常挂在胸前、腰间或固定在身体上。注意：桌上同样可能放置**小型设备**。

【算"出现"的情形（任一即可）】
- 装置本体出现在画面任何位置，包括只露出一角
- 装置的屏幕出现在画面中（屏幕点亮或熄灭都算）
- 装置出现在画面下边缘、左右两侧、或被手部分遮挡
- 任意一帧出现即算出现

【不算问题的情形】
- 桌上的任务道具：积木、碗、收纳盒，以及**任务描述里明确要求操作的**平板或手机
- 桌面、桌腿、隔断、墙面等固定环境结构
- 操作员的手、手臂、衣物

【必须回答】
1. 四选一：未出现 / 疑似出现但看不清 / 明确出现 / 无法判断
2. 若选"疑似"或"明确出现"：给出至少 2 个帧 ID，并说明
   - 是什么（设备本体 / 设备屏幕 / 小型设备）
   - 在画面哪个位置（下边缘 / 左下 / 右下 / 左侧 / 右侧 / 中央）
   - 大约占画面多大比例（如 <2% / 2–10% / >10%）
3. 反证：有没有帧显示画面中完全没有该设备？给出帧 ID。
4. 若你收到的帧没有覆盖整条视频，必须说明并考虑选"无法判断"。

【特别注意】
本组输入中有一部分是"画面底部裁切放大图"，用于帮助你看清下缘细节。
若在裁切图中看到疑似设备，请按其对应的时间/序号引用。
```

# 第五部分：聚合规则（确定性代码，模型不参与）

```python
def decide(r):
    # 一票否决
    if r.q1.verdict == "明确出现":                    return "delete", "device_exposed"
    if r.q5.verdict == "出现":                        return "delete", "face"
    # 任务类
    if r.q2.verdict == "未完成":                      return "delete", "task_incomplete"
    # 画面质量
    if r.q3.verdict == "严重模糊":                    return "delete", "blur_severe"
    if r.q3.verdict == "画面发白":                    return "delete", "blur_overexposed"
    # 时序类（阈值待校准）
    if "有抖动" in r.q4.flags and (r.q4.duration_s or 0) >= 10:  return "delete", "shake"
    if "有长时间静止" in r.q4.flags:                  return "delete", "static"
    if "疑似测试片段" in r.q4.flags:                  return "delete", "test_clip"
    # 证据不足 → 交人工，绝不猜
    if "无法判断" in (r.q1.verdict, r.q2.verdict, r.q3.verdict): return "needs_human", "unknown"
    if not r.coverage.covers_whole_video:             return "needs_human", "coverage"
    if r.q1.verdict == "疑似":                        return "needs_human", "device_suspect"
    if r.q3.verdict == "中心区域模糊":                return "needs_human", "center_blur"
    return "keep", ""
```

所有阈值是**代码常量**，可按"怕误删 / 怕漏放"整体平移。
