04 / AGENTIC AC-WM BRANCH

生成、验收、修复，
每一步都有证据。

新增分支沿用现有 workflow 的候选生成、评分、修复与审计结构，但增加动作契约、模型能力路由和强制人工门。失败不会被平均分掩盖，也不会被从展示中删除。

  1. 01CONTRACT

    解析语言目标、阶段和动作表示；显式声明 camera 或 robot_base 坐标系。

  2. 02ROUTE

    依据 skeleton、EEF、joint 或 pointmap 选择 OSCAR、BWM 或 Kinema4D。

  3. 03GENERATE

    GPU 预检、固定 revision、记录 seed 与环境；每次运行写入全新实验目录。

  4. 04GATE

    五项数值门与强制人工复核逐条通过才接受；本次为 2 / 3 动作通过。

  5. 05REPAIR

    右移改用上提竖直模板 + 右向弧线，并由 OSCAR 重新生成完整关节运动；刚性平移版降级为反证。
