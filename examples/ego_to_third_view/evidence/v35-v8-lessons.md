# 有效修正与失败经验

这些是本系列从固定第三人称重建到 v35/v7/v8 的工程结论，不是把每个中间版本都当作成功。

## 几何和视觉

- 保持原 ego 操作者的世界侧别。曾尝试让人从第三人称画面底边/相机方向或桌子另一侧发出动作，
  改变了动作来源，不能作为遮挡/构图修复。渲染相机保持独立。
- 从“画长前臂连接画面边缘”改成固定人体两连杆 IK。固定上臂/前臂、一个共享躯干；
  不让每条手臂单独带动一块衣服/身体整体平移。正常长度是人物参数，不是屏幕像素长度。
- 躯干根平移及 roll/pitch 固定，平滑 yaw 保留。肘弯曲平面随 reach axis 平行运输，
  限制相对旋转速度，防止手腕旋转导致整个肘部翻转。只平滑肘位置可能破坏臂长，不能替代 IK。
- 对已观测抓持区间使用物体相对 medoid 手形，平滑进出抓持；不是整段冻结所有手。
  不可观测对称轴旋转需显式证据才可 world-lock。旧例的刚性凸包贴合只是近似，
  其最大顶点修正曾达到约14.7cm，不能把这当通用安全修正额度或精确接触证明。
- 房间、桌面、白板保持稳定；此次“无柜子/显示器”等限制属于该场景要求。
  换场景应保留新场景自身内容，而不是永远套实验室模板。
- DiT 改为单次连续12秒，避免多个4秒片段切换引起身体、背景、物体状态重置。
  H3 最大时长以已验证适配器为准；长视频不能直接三段拼接然后声称无缝。

## 时序

- 输出总时长相同不等于事件同步。旧 v7 的动作仍提前约0.5–1秒，
  即使控制视频和输出都标记12秒也不能免除事件检查。
- 发现输入 VAE 的 `17*n+5` 对齐将288参考帧下裁为277；新代码向上补294帧副本，
  保留原 EGO/SIM，最终导出前288帧。这是输入边界修复，不能宣称解释全部时序漂移。
- v8 按抓持/搬运/停止/松手分段 PCHIP 重映射，保留画面，不再重跑 H3/SIM。
  19个首尾/事件/姿态节点仅属于对应文件哈希，不能带到下个视频。
- 独立蓝色物体水平进度10/25/50/75/90%检查：提前0.667–0.708秒 → 偏差−0.042～+0.125秒。
  仅此运动指标；不等于所有手势/竖直路径误差都小于0.125秒。
- 首尾保持、288帧24fps12秒；37次重复源帧过渡。平滑的是时间函数，非生成新中间画面，可能有顿感。

## H3 / Sol / 缓存

- 实际 v7 成功路径为4× RTX PRO 5000 72GB、FSDP+Ulysses4、BF16、Triton Sol+FBC，
  24请求步/23去噪决策，14次复用/9次计算。加载244.650秒，请求893.766秒，去噪803.476秒。
- 集成必须在每个 spawned rank 注册，不只主进程。不能因为配置写有 Sol/FBC 就声称实际执行；
  检查各 rank sparse/backend/cache/gate 事件，暖多请求使用独立 epoch，不能串用残差。
- 原 raw-kernel prefix 存在超差，但该区域随后被 exact-prefix 输出覆盖。正确门槛应覆盖最终
  **完整 consumed output**（prefix和target都检查），不因被丢弃的值拒绝，也不漏验prefix。
  原 max/mean/relative-L2 门槛保持；对 BF16 参考疑点用显式 FP32/禁TF32复核，真实误差仍拒绝。
- 全张量临时 FP32 统计曾 OOM，改有界块统计；不能靠缩小审查区域或放宽误差解决。
- 原生文本 FSDP CPU offload 出现 Tensor/DTensor 卷积混用；成功路径保留 TP loader，编码后
  使用 vanilla D2H。VAE offload 曾伴随 SIGBUS，未证实根因；不把该失败路径设默认。
- 保留同一已加载 worker 可省加载，但不自动省13分钟去噪。当前新 resident 路径的实际第二次
  H3暖请求和同NUMA收益尚待测，不能把估算说成实测。
- 旧成功卡组2/4/5/6跨NUMA；新默认禁止跨NUMA，所以旧GPU编号不能复制为新生产配置。
  模型/显存/通信拓扑需匹配测试，不能把“更多卡”“打开compile”“减少步数”当必然无损加速。
- 进度条曾因更新稀疏被误诊卡死；后续确认采样实际仍在推进。以真实错误、进程状态和明确超时
  判断，不因短期无新日志停止仍在计算的任务；只清理本任务拥有的进程。
